# Проект 

проект JavaScript и вёрстке. Сборник мини-игр и интерактивных задач.

## 🎮 Что внутри

В проекте реализованы:
*   **Генератор случайных цветов** — кнопка меняет цвет фона секции.
*   **Игра «Угадай число»** — логика сравнения загаданного и введенного числа.
*   **Арифметический тренажёр** — проверка простых вычислений.
*   **Игра «Переверни текст»** — работа со строками.
*   **Адаптивная вёрстка** — стили для мобильных и планшетов (SCSS).


## 🛠️ Технологии

*   **HTML5** — семантическая разметка.
*   **SCSS** — стилизация, переменные, медиа-запросы (`_mobil.scss`, `_tablet.scss`).
*   **JavaScript (ES6+)** — логика игр, работа с DOM, генерация случайных чисел.
*   **GitHub Pages** — деплой проекта.
